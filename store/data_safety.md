## Answers (paste in this order)

**Section 1. Data collection and security**
1. Does your app collect or share any of the required user data types? **No.**
2. Is all of the user data collected by your app encrypted in transit? Not asked (nothing is collected). If the Console insists: **Not applicable, nothing is transmitted.**
3. Do you provide a way for users to request that their data is deleted? Not asked. If it insists: **Not applicable.** Nothing leaves the phone; uninstalling the app or clearing its storage deletes everything. There are no accounts.

## Why "No" is true (code evidence)

Google counts data as collected only when it is transmitted off the device. Sound Out transmits nothing.

| Question | Finding | Where |
|---|---|---|
| Network calls | None. No fetch, XMLHttpRequest, WebSocket, sendBeacon, window.open, iframe or outside URL in the app code. Audio and pictures load from the app's own files. | grep of app/src and app/index.html, 2026-10-10: zero code hits (the one match is the word "analytics" inside the privacy text in app/src/privacy.js) |
| Network permission | Manifest removes INTERNET and AD_ID with `tools:node="remove"` so a library cannot add them back. | app/android/app/src/main/AndroidManifest.xml lines 6-7 |
| Network allowed by build | `usesCleartextTraffic="false"`, no `server.url`, no `allowNavigation`, `allowMixedContent: false`. A Content-Security-Policy is injected in production builds. | AndroidManifest.xml, app/capacitor.config.json, app/vite.config.js |
| Third-party SDKs | None. Dependencies are only @capacitor/android, app, core, status-bar. `google-services.json` is absent, so the Google Services plugin is not applied. | app/package.json, app/android/app/build.gradle |
| Analytics, crash reporting, ads | None (no gtag, firebase, sentry, mixpanel, ad libraries). | grep, same run |
| Storage | IndexedDB database `sound-out` (settings, profiles, progress, review cards) on the device only. `localStorage` holds the first-time demo flag (`so-gate-demo-<profileId>`) and the grown-up gate's try counter and lockout time. No cookies. | app/src/db.js, app/src/gate.js:39-42, app/src/grownup.js |
| Backup and transfer | `android:allowBackup="false"`: nothing is copied to Google or to a new phone. | AndroidManifest.xml |
| Sensors, microphone, camera, location | Not used. No getUserMedia, SpeechRecognition, MediaRecorder or geolocation; no RECORD_AUDIO, CAMERA or location permission. The mic icon is only a drawing. | grep app/src; manifest |
| Personal info asked | None. Profile labels are generated by the app ("Child 1", "Grown-up 1"). No name, email, age or birthday field. | app/src/onboarding.js |
| Typed text | One free-text box (Level 5-7 writing). Compared on screen with a model answer, not stored, not sent. | app/src/screens/session/write.js |
| Links, contact, purchases | None in the app. The privacy screen shows its web address as plain text behind a grown-up gate. | app/src/privacy.js, store/families_fixes.md |
| Teacher's voice | Pre-recorded AI-generated audio files inside the app; nothing is generated online. | privacy.html, listing |

## Change triggers (any one means redo this form, privacy.html, the in-app privacy screen and listing_en.md)
- Any network request, or the INTERNET permission, including downloadable language-help packs.
- Any analytics, crash or ad SDK.
- A tappable link, email button, export, share or backup feature.
- Microphone use, for example to grade pronunciation.
