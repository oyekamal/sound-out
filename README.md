# Sound Out — learn to read English, any age, offline

Play title: **Sound Out: Read English** · package `com.oyekamal.soundout` · see `store/NAME-ASO.md`.

A free, offline-first Android/PWA app that takes anyone in the world (age 4 to 60, any home language or none) from the first letter sound to reading real English text. **Scope rule (Kamal, 2026-10-06): global first.** The core works with no home language at all; home-language help (UI voice, glosses, interference notes) is an optional downloadable helper pack, and Urdu is just one of them. Built on the open course [english-reading-course](https://github.com/oyekamal/english-reading-course) (8 levels, synthetic phonics) and on the shell of the shipped [Urdu Qaida](https://github.com/oyekamal/urdu-reading-course) app.

## Prototype (2026-10-06): see it and play it

A first browser slice so Kamal can see how the course looks and works. It is not the v1 app.

**Run it**
```
cd app && npm i && npm run dev        # http://localhost:5317
```
- `?fast` speeds audio up (used by the test driver). `?sliced` plays the isolated sounds cut from Kokoro words instead of the IPA-direct renders.
- **Sound check page:** http://localhost:5317/listen.html lists every Level 1 sound three ways (sliced from a word, IPA direct, the source word) plus the s-a-t → "sat" blend with 350 ms gaps. This page is for the voice decision.

**What you can play:** "Who is reading?" (child or grown-up, spoken), an optional skippable language-help grid, then straight into L1.02. Track A (child): Pebble, a village that grows one piece per sound, stickers, Sittings A-D + Read + Listen + Show what you know, and L1.03-L1.04 after that. Track B (grown-up): plain screens, no mascot, "words to remember", sittings merged (ABC, D, Check). Exercises: Hear it, Meet it, Trace, Blend it (E5, with the self-report "I said it"), the tap gate E6d (2×2 option grid, sound-by-sound repair, no whole-word reveal), Spell it, Tricky word map, Read it (tap a word: sounds first, whole word on the second tap), Listen & Talk (picture after each chunk, one Tier-2 word, two questions), Show what you know (the lesson's own bar). Sittings are on demand: the next one opens when the mini check passes. Progress, review cards and "days practised" (never resets) are stored per profile in IndexedDB. No microphone, no network.

**Real vs placeholder**
| Part | Status |
|---|---|
| Lesson content (L1.02-L1.04 playable; all 108 lessons parsed) | real, from english-reading-course via `tools/parse_course.py` |
| Tap-gate options | real rule (2×2 grid), generated by `tools/gen_options.py`; 36 of 242 items had to relax "real foils for real words" (flagged `relaxed`) |
| **Every voice clip** | **PLACEHOLDER: Kokoro `af_heart` computer voice.** The real app records a human Sound Teacher for Levels 0-3 |
| Isolated sounds (/s/, /t/ ...) | placeholder: Kokoro asked to say one phoneme; a sliced alternative is on listen.html |
| Pictures, Pebble, village art | placeholders (simple SVG shapes) |
| Language help (Urdu, Spanish, Portuguese) | button only; no helper packs |
| Listen & Talk answers | picture buttons are placeholders; any answer is accepted |
| Trace score | share of the letter's guide covered; no stroke order yet |

**Rebuild content and audio**
```
python3 tools/parse_course.py            # lessons -> content/lessons/*.json, gpc, lexicon, coverage.md
python3 tools/gen_options.py             # tap-gate option grids -> content/options.json
python3 tools/gen_audio.py plan          # list every clip
<kokoro-venv>/bin/python tools/gen_audio.py render 0 1
python3 tools/gen_audio.py encode        # trim, pad 40/80 ms, -3 dBFS, Opus -> app/public/audio
<kokoro-venv>/bin/python tools/slice_phonemes.py   # sliced sounds + listen.html data (run after parse_course: it appends to coverage.md)
python3 tools/drive.py                   # Playwright walk-through + rule checks + screenshots
```
